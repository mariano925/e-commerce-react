# E-commerce React

Aplicación de e-commerce desarrollada con React + Vite.

## Tecnologías

- React
- Vite
- JavaScript
- Tailwind CSS

## Descripción

Proyecto de e-commerce desarrollado paso a paso con React.

El objetivo es construir una tienda online completa y aplicar diferentes conceptos de desarrollo frontend.

## Conceptos implementados

- Componentes reutilizables
- Props
- Renderizado de listas con `map()`
- Eventos con `onClick`
- Separación de responsabilidades
- Organización de carpetas
- Tailwind CSS
